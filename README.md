# Grown, Not Built

A narrated, hands-on guide to how AI like ChatGPT, Claude and Gemini really works, for everyone from 10 to 80.

**Open it here:** https://jfrascino.github.io/grown-not-built/

Twelve short chapters, about fifty minutes, with narration, music and things to try:

1. How We Got Here
2. The Guessing Game
3. Words Become Numbers
4. A Brain of Knobs
5. Growing a Model
6. Raising a Model
7. Talking to AI
8. Inside the Black Box
9. Is It Alive?
10. The Risks, Plainly
11. The Benefits, Honestly
12. What's Next

Every number in the lesson is sourced. Tap **Sources** inside the lesson to see where each one comes from. Facts are current as of October 2026.

Built with Claude Opus 5.5 (Anthropic). Narration voice: “Sarah” from ElevenLabs. Music: Google Lyria.
